1. КАК ОТКРЫТЬ И ЧИТАТЬ
================================================================
1) Откройте файл База_знаний.html двойным щелчком (любой браузер:
   Chrome, Edge, Firefox, Safari). Интернет не нужен, логотип и
   все стили встроены в файл.
2) Введите пароль (по умолчанию: 2026) и нажмите «Войти» или Enter.
   Пока пароль не введён, материалы не отображаются. Пока вкладка
   открыта, повторно вводить пароль не нужно.
3) Оглавление: слева меню со всеми документами. Выбранный документ
   раскрывает свои разделы. Кнопка «⌂ Оглавление» открывает главную
   страницу с карточками документов.
4) Поиск: строка над контентом. Ищет по ВСЕМ документам сразу.
   Результаты показывают документ, раздел и фрагмент с найденным
   словом, выделенным лаймовым маркером. Клик по результату открывает
   нужное место, слово подсвечивается и в самом документе. Чтобы
   убрать подсветку — очистите строку поиска. Ищите по началу слова
   («распис» найдёт «расписание», «расписания»). Если слов несколько,
   найдутся блоки, где есть все они.
5) Копирование: рядом с шаблонами сообщений и блоками, помеченными
   copy:true, есть кнопка «▸ Скопировать». Нажмите — текст попадёт в
   буфер обмена (без разметки), кнопка покажет «✓ Скопировано».
   Обычный текст на странице тоже можно выделять и копировать мышью.

================================================================
2. КАК УСТРОЕН ФАЙЛ
================================================================
Откройте База_знаний.html в блокноте или редакторе кода (VS Code,
Notepad++, Sublime; НЕ в Word). Внутри три части:

  1. CONFIG — настройки: пароль, названия, шапка, подвал.
  2. DOCS   — вся база знаний (список документов). ЗДЕСЬ ВЫ РАБОТАЕТЕ.
  3. ДВИЖОК — код работы сайта. Ничего не менять.

Находите нужное место по заголовкам-комментариям:
  «1. НАСТРОЙКИ», «2. ДОКУМЕНТЫ», «3. ДВИЖОК».

Правила редактирования:
  - Весь текст пишется в одинарных кавычках: 'текст'.
  - Если внутри текста нужна одинарная кавычка, пишите её так: \'
    Лучше использовать «ёлочки» — они не мешают.
  - Перенос строки внутри текста: \n
  - Между элементами списка обязательна запятая. После последнего
    элемента запятая необязательна.
  - Скобки { } [ ] должны закрываться. Самая частая ошибка — забытая
    запятая или скобка. Если после правки страница пустая или не
    открывается, откатите последнее изменение.
  - Сохраняйте файл в кодировке UTF-8 и обновляйте страницу в браузере
    (F5), чтобы увидеть результат.
  - ВСЕГДА делайте копию файла перед большой правкой.

================================================================
3. КАК ПОМЕНЯТЬ ПАРОЛЬ И НАЗВАНИЯ
================================================================
В блоке CONFIG:

  password: '2026',   ← ПАРОЛЬ. Замените 2026 на свой: password: 'мойпароль',
  org:      '...',    ← надзаголовок капсом в шапке (название организации)
  title:    '...',    ← большой заголовок в шапке
  subtitle: '...',    ← подзаголовок. Для перечисления: 'Специальность · База · Группы'
  date:     '',       ← чёрная плашка справа (дата, период). '' — плашка скрыта
  badge:    '...',    ← лаймовый бейдж под плашкой. '' — скрыт

Подвал (два серых блока внизу страницы):

  footer: {
    rulesTitle: 'Как пользоваться',     ← заголовок левого блока
    rules: 'текст правил',              ← левый блок (поддерживает **жирный**)
    contactsTitle: 'Контакты',          ← заголовок правого блока
    contacts: [['Куратор','Иванова А.А.'], ['Почта','mail@college.ru']]
  }                                      ← пары [название, значение]; [] — скрыть блок

Внимание: пароль хранится в файле открытым текстом. Это защита от
случайного просмотра, а не от человека, умеющего открыть код файла.
Не размещайте в базе данные, требующие строгой защиты.

Название вкладки браузера меняется в самом верху файла: строка
<title>...</title>.

================================================================
4. ДОКУМЕНТЫ: КАК ДОБАВИТЬ, РАСПРЕДЕЛИТЬ, УДАЛИТЬ
================================================================
Каждый документ — один блок { ... } внутри списка DOCS = [ ... ].
Порядок в списке = порядок в оглавлении и нумерация (01, 02, ...).

Скелет нового документа:

  {
    id: 'raspisanie',                 // уникальный код: латиница, цифры, дефис, без пробелов
    title: 'Расписание и пары',       // название в меню, оглавлении и поиске
    eyebrow: 'РАЗДЕЛ',                // надзаголовок капсом над названием (необязательно)
    desc: 'Как устроены пары и где смотреть расписание',  // строка на карточке оглавления
    blocks: [
      // здесь блоки содержимого (см. раздел 5)
    ]
  },

Как добавить документ:
  1) Скопируйте скелет выше.
  2) Вставьте его в DOCS после запятой предыдущего документа
     (между документами всегда запятая: }, {).
  3) Задайте уникальный id, title, desc.
  4) Наполните blocks.

Как поменять порядок: переставьте блоки { ... } местами целиком.
Как удалить документ: удалите блок { ... } целиком вместе с запятой
после него. Поставляемый «Пример документа» (id: 'example') удалите
после изучения. Ссылки, ведущие на удалённый документ, перестанут
работать — найдите их через поиск по файлу (Ctrl+F) по его id.
Как переименовать документ: меняйте только title. id менять можно,
но тогда обновите все ссылки на него (см. раздел 7).

Рекомендация по структуре: один документ — одна тема (например:
«Расписание», «Документы студента», «Шаблоны сообщений», «Контакты»).
Внутри документа делите материал на разделы (h2). Для долгих
документов используйте 5–10 разделов, в списках — не более 5–7 пунктов.

================================================================
5. БЛОКИ СОДЕРЖИМОГО (CТРОИТЕЛЬНЫЕ ЭЛЕМЕНТЫ ДОКУМЕНТА)
================================================================
Блоки перечисляются внутри blocks: [ ... ] через запятую, в том
порядке, в каком должны выводиться на странице. Поле t — тип блока.

--- 5.1 Раздел (заголовок H2) ---------------------------------
{t:'h2', id:'prava', text:'Права и обязанности'},
  Автоматически получает лаймовый номер 01, 02... и попадает в меню
  слева. id — уникальный в рамках документа код для ссылок.
  Необязательно: eyebrow:'ТЕМА' — подпись капсом рядом с номером.

--- 5.2 Подраздел (H3) ----------------------------------------
{t:'h3', id:'srok', text:'Сроки'},

--- 5.3 Абзац -------------------------------------------------
{t:'p', text:'Текст абзаца. **Жирный**, ==маркер==, [[doc|ссылка]].'},
  Добавьте copy:true — появится кнопка «Скопировать».

--- 5.4 Маркированный и нумерованный списки -------------------
{t:'ul', items:['**Ключевое слово:** пояснение.', 'Второй пункт']},
{t:'ol', items:['Шаг первый.', 'Шаг второй.']},
  ul — синие маркеры, ol — шаги в чёрных квадратах с цифрой.

--- 5.5 Ключ — значение (контакты, реквизиты) -----------------
{t:'kv', rows:[['Куратор','Иванова А. А.'], ['Сайт','[college](https://site.ru)']]},

--- 5.6 Блок «Важно» ------------------------------------------
{t:'important', title:'Важно', text:'Срок сдачи — **до 25 числа**.', copy:true},
  title — текст лаймового ярлыка (по умолчанию «Важно»).

--- 5.7 Информационный блок (серый) ---------------------------
{t:'info', title:'Как устроена пара', text:'Пояснение...', copy:true},

--- 5.8 Цитата / ключевой тезис (чёрная плашка) ---------------
{t:'quote', text:'Главная мысль, ==важное слово== лаймом.', copy:true},

--- 5.9 Шаблон сообщения (с кнопкой копирования) ---------------
{t:'msg', title:'Напоминание студенту',
 text:'Здравствуйте, {имя}!\nНапоминаю о сроке до {дата}.\nС уважением, {куратор}'},
  Кнопка «Скопировать сообщение» есть всегда. Переменные для подстановки
  пишите в { } — это обычный текст, пользователь заменит их сам.
  Переносы строк — \n. Разметка (** и ==) при копировании убирается,
  ссылки копируются как «текст (адрес)».

--- 5.10 Таблица ----------------------------------------------
{t:'table', side:true, copy:true,
 head:['Время','Пн','Вт'],
 rows:[['1 пара','Математика',''], ['2 пара','','Информатика']],
 foot:['Итого','1','1']},
  head — заголовки колонок; rows — строки; в каждой строке столько
  значений, сколько колонок. '' — пустая ячейка (серая, без текста).
  side:true — первая колонка оформляется как боковая серая.
  foot — итоговая строка (необязательно). copy:true — кнопка копирования
  таблицы (значения через табуляцию, вставляется в Excel).

--- 5.11 Карточки-ссылки --------------------------------------
{t:'cards', items:[
  {title:'Документы', text:'Где взять справку', to:'dokumenty'},
  {title:'Раздел', text:'Сразу к разделу', to:'dokumenty#spravki'}
]},
  to — id документа или id документа#id раздела. Без to карточка
  просто информационная.

--- 5.12 Кнопка-ссылка на сайт --------------------------------
{t:'btn', text:'Открыть портал', url:'https://portal.ru'},
  Одна кнопка на смысловой блок.

--- 5.13 Разделитель (градиентная полоса) ---------------------
{t:'sep'},

================================================================
6. ВЫДЕЛЕНИЕ ВНУТРИ ТЕКСТА
================================================================
Работает во всех текстовых полях (text, items, rows, ячейки таблиц,
desc, rules, значения контактов):

  **текст**                жирный (термины, даты, сроки)
  ==текст==                лаймовый маркер (1–2 фразы на страницу,
                           только самое критичное: дедлайны, обязательные действия)
  [[id|текст]]             внутренняя ссылка на документ
  [[id#раздел|текст]]      внутренняя ссылка на раздел документа
  [текст](https://адрес)   внешняя ссылка (открывается в новой вкладке)
  \n                       перенос строки

Не используйте курсив, красный цвет и подчёркивание обычного текста —
это нарушает гайдлайн.

================================================================
7. КАК СОЗДАВАТЬ ССЫЛКИ
================================================================
Внутри базы:
  На документ:    [[raspisanie|Расписание пар]]
  На раздел:      [[raspisanie#asinkhron|Асинхронные занятия]]
  Здесь raspisanie — id документа, asinkhron — id раздела (поле id
  у блока h2 или h3). Если id раздела не задан, он генерируется
  автоматически, поэтому для ссылок ВСЕГДА задавайте id у h2/h3.
Внешние:        [Портал](https://portal.ru)
Карточки:       {t:'cards', items:[{title:'..', text:'..', to:'raspisanie'}]}
Из других мест (мессенджер, почта) на документ можно сослаться
адресом файла с якорем: База_знаний.html#/raspisanie/asinkhron
(работает, если у получателя файл лежит там же и он знает пароль).

Правила id: только строчные латинские буквы, цифры и дефис,
без пробелов; уникальны в пределах документа (для разделов) и
во всей базе (для документов).

================================================================
8. КАК СОЗДАВАТЬ НОВЫЕ ШАБЛОНЫ
================================================================
«Шаблон» — это готовая заготовка, которую вы копируете внутри кода.

А) Шаблон сообщения для куратора/студента:
   добавьте блок {t:'msg', ...} (п. 5.9). Удобно собрать их в один
   документ «Шаблоны сообщений» и каждую группу сообщений вынести
   в отдельный раздел h2 («Напоминания», «Отказы», «Приглашения»).

Б) Шаблон нового документа:
   скопируйте скелет из раздела 4 и сохраните его отдельно в
   текстовом файле как заготовку. Для нового документа вставляйте
   заготовку в DOCS и меняйте id, title, desc.

В) Шаблон страницы-«регламента» (рекомендуемый порядок блоков):
   h2 «Что это» → p → important (срок/главное) → ol (шаги) →
   h2 «Шаблон сообщения» → msg → h2 «Контакты» → kv.

Г) Новый тип блока (для разработчика): в части «ДВИЖОК» функция
   renderBlock — добавьте новый case по образцу существующих и
   стили (CSS) в верхней части файла. Для обычного наполнения
   этого не нужно.

================================================================
9. ПОИСК: КАК ПОВЫСИТЬ КАЧЕСТВО
================================================================
Поиск индексирует все тексты всех блоков автоматически (никаких
дополнительных настроек). Чтобы материалы находились лучше:
  - называйте документы и разделы теми словами, которыми будет
    искать пользователь («Как оформить справку», а не «Процедура 4.2»);
  - в desc документа пишите ключевые слова;
  - один раздел — одна тема, тогда результат ведёт точно к месту;
  - добавляйте синонимы в текст («пропуск (справка, больничный)»).
Блоки без текста (разделитель sep) в поиске не участвуют.

================================================================
10. ОФОРМЛЕНИЕ: ЧТО УЖЕ ЗАШИТО В СТИЛЬ (по гайдлайну)
================================================================
Палитра, скругления, шапка с градиентом и логотипом, чёрные плашки
заголовков таблиц, белые карточки с синей полосой, лаймовые кнопки и
чипы, отсутствие теней — всё уже настроено. Цвета лежат в начале
блока <style> в переменных --k (чёрный), --b (синий), --bl (светлый
синий), --l (лайм), --bg (подложка), --g (серый). Если брендбук
уточнит HEX-коды (гайдлайн отмечает, что синий, лайм и шрифт стоит
сверить), замените значения в этих переменных — цвет изменится везде.
Шрифт задаётся в body { font-family: ... }; по умолчанию Onest →
Manrope → Montserrat → Arial. Строка для подключения Onest из
интернета есть в начале файла в комментарии (раскомментируйте её).

Логотип встроен в файл (экран входа и шапка). Заменить его можно,
подставив новую картинку в виде data:-ссылки в атрибуты src двух
тегов <img> — либо обратитесь к разработчику. Не растягивайте,
не перекрашивайте логотип.

================================================================
11. ЧАСТЫЕ ОШИБКИ
================================================================
- Страница пустая после правки: пропущена запятая между блоками или
  не закрыта скобка/кавычка. Откатите последнюю правку.
- Апостроф в тексте ломает код: используйте «ёлочки» или \'
- Ссылка не работает: проверьте id документа и раздела (латиница,
  без пробелов) и что они совпадают с записанными в [[ ]].
- Поиск не находит новый текст: сохраните файл и обновите страницу (F5).
- Кнопка копирования не срабатывает при открытии из некоторых
  мессенджеров/просмотрщиков: откройте файл обычным браузером.
- Новая версия базы: заменяйте файл целиком и рассылайте всем,
  у кого он сохранён, — каждый пользователь работает со своей копией.

================================================================
12. БЫСТРАЯ ПАМЯТКА
================================================================
Поменять пароль         → CONFIG → password
Поменять название/шапку → CONFIG → org / title / subtitle / date / badge
Контакты и правила      → CONFIG → footer
Новый документ          → DOCS → скопировать скелет (раздел 4)
Новый раздел            → {t:'h2', id:'..', text:'..'}
Таблица / список        → {t:'table'...} / {t:'ul'...} / {t:'ol'...}
Важное                  → {t:'important'...}, ==маркер==, **жирный**
Шаблон сообщения        → {t:'msg'...}
Кнопка копирования      → copy:true (или блок msg)
Ссылка внутри базы      → [[id|текст]] или [[id#раздел|текст]]
Ссылка наружу           → [текст](https://...)
